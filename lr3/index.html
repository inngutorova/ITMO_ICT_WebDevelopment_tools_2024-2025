Лабораторная работа 3: Микросервисная архитектура FastAPI с Celery и Docker

Введение

Техническая архитектура

Сервисы инфраструктуры

main-api (port: 8000)

Технологии: FastAPI (Python 3.9)
Основное API приложение, обрабатывающее бизнес-логику системы.

parser** (port: 8001)

**Технологии: FastAPI (Python 3.9)
Сервис парсинга внешних данных. Интегрируется с API и базами данных.

postgres (port: 5432)

Технологии: PostgreSQL 13
Основная реляционная база данных. Хранит структурированные данные системы.

redis (port: 6379)

Технологии: Redis 6
Брокер сообщений и кеш-хранилище. Обеспечивает высокую скорость операций.

celery

Технологии: Celery 5.2
Асинхронный обработчик фоновых задач (например, очередь запросов для парсера).

Детали реализации

1. Основное API (app/main.py) - добавленные эндпоинты

from fastapi import FastAPI
from celery.result import AsyncResult
from .celery_worker import celery_app

app = FastAPI()

class ParseRequest(BaseModel):
    url: str


@app.post("/async-parse")
async def async_parse_url(request: ParseRequest):
    task = parse_url_task.delay(
        url=request.url,
        parser_service_url=os.getenv("PARSER_SERVICE_URL", "http://parser:8001")
    )
    return {
        "message": "Parsing started",
        "task_id": task.id,
        "status_url": f"/task-status/{task.id}"
    }


@app.get("/task-status/{task_id}")
async def get_task_status(task_id: str):
    task_result = AsyncResult(task_id, app=celery_app)

    if task_result.failed():
        error = task_result.result
        raise HTTPException(
            status_code=error.get('code', 500),
            detail=error.get('detail', 'Unknown error')
        )

    return {
        "task_id": task_id,
        "status": task_result.status,
        "result": task_result.result if task_result.ready() else None
    }

2. Конфигурация Celery (app/celery_app.py)

from celery import Celery
import os

celery = Celery(
    'tasks',
    broker=os.getenv('REDIS_URL', 'redis://redis:6379/0'),
    backend=os.getenv('REDIS_URL', 'redis://redis:6379/0'),
    include=['tasks']
)

celery.conf.update(
    task_serializer='json',
    result_serializer='json',
    accept_content=['json'],
    timezone='Europe/Moscow',
    enable_utc=True,
)

3. Docker Compose (docker-compose.yml)

    depends_on:
      db:
        condition: service_healthy


  parser:
    build:
      context: ./parser
      dockerfile: Dockerfile
    ports:
      - "8001:8001"
    environment:
      - DB_TIME=postgresql://postgres:password@db:5432/time_db_copy
    depends_on:
      db:
        condition: service_healthy

  db:
    image: postgres:13
    environment:
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=time_db_copy
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    healthcheck:
      test: [ "CMD-SHELL", "pg_isready -U postgres" ]
      interval: 5s
      timeout: 5s
      retries: 10

  redis:
    image: redis:6
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

  celery:
      build:
        context: ./app
      command: celery -A celery_app worker --loglevel=info
      environment:
        - DB_TIME=postgresql://postgres:password@db:5432/time_db_copy
        - REDIS_URL=redis://redis:6379/0
        - PARSER_SERVICE_URL=http://parser:8001
        - PYTHONPATH=/app
      volumes:
        - ./app:/app
      depends_on:
        - redis
        - db
